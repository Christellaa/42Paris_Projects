# 42Paris_Projects

This repository contains projects completed as part of my cursus at 42 School, a software engineering school known for its hands-on and project-based learning approach.

The projects cover various areas of computer science, ranging from programming and algorithms, to systems, networking and infrastructure.

# About 42 School

42 offers an intensive program with no classes or teachers, based entirely on:
- Hands-on project development
- Self-directed learning and problem-solving
- Peer-to-peer collaboration
- Code reviews and knowledge sharing

The curriculum emphasizes autonomy, rigor, adaptability and continuous learning.

### Core Curriculum (2 years)
- Programming: C, C++, web development
- Algorithms, data structures
- Systems programming: processes, memory management
- Networking & system administration
- Software architecture
- Teamwork, collaborative project management

### Specialization (3 years, ongoing)
Currently pursuing an advanced specialization focused on:
- DevOps and cloud infrastructure: containerization (Docker, Kubernetes), CI/CD, monitoring and automation
- Systems engineering: low-level programming, memory management, processes and system calls
- Cybersecurity: system security, vulnerability analysis, authentication, encryption and security assessment
- Networking: network protocols (BGP, OSPF), communication, network architecture and services
